# Monitoring App

Only Android Devices!

App to monitoring phone sensors, app usage, battery level, etc. With graphs, user friendly interface.

Main-Front page: Turn on/off background monitoring, Temperature sensors in real time, Battery, App usage today.
Sensors Page: You can choose thermal sensors that you want to be recorded.
Apps Page: Selected apps for first page, and you can set time limit to app for day, to get notification later.
Stats Page: Complex page, graphs for every selected sensor, battery and etc.
Settings Page: Theme, temperature in c/f, Enable background monitoring, Poll Interval, Keep data for how long, Helper to turn off the battery optimization/MIUI autostart. Test notifications for temperature and app time.

App was made on Flutter/Dart + Kotlin for background service, bridge between dart and kotlin, Database helper and etc.
